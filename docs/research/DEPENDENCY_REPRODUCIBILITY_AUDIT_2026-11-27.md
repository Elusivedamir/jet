## Supply-chain scan interpretation

- SBOMs and scanner reports are attached to CI artifacts for the exact run.
- A zero-finding report means no matching issues were detected by that tool/database/version at scan time; it is not a security certification.
- License inventories require human compatibility review. Unknown, custom or project-level license declarations require explicit resolution.
- Third-party GitHub Actions are still referenced by version tags rather than immutable SHAs; pinning is a separate hardening task.

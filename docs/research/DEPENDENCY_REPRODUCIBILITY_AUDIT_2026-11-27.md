Maven is run with strict checksum mode. The resolved dependency tree is emitted as a JSON artifact, and a CycloneDX SBOM is generated. This makes the exact resolved graph inspectable for each build but is not equivalent to a committed lockfile. A full transitive pinning strategy remains an open decision.

- CycloneDX SBOM;
- Trivy filesystem vulnerability and license report;
- ecosystem-specific inventory where available (Go vulnerability/license reports; npm audit and license-checker report; Maven dependency tree).

A scan is considered evidence only when its report artifact exists, includes the exact tested commit, and has been reviewed. A clean scan does not prove the absence of all vulnerabilities. License inventories identify declared licenses; legal compatibility still requires human review. That result predates the corrected lockfile CI run and is not a current security clearance.
